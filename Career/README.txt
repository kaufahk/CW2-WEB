CareerLink — Box Format Edition
================================
This version follows the box-based layout style of the HTML example provided.

Included pages:
- index.html
- jobs.html
- internships.html
- companies.html
- job-details.html
- dashboard.html
- auth.html
- pricing.html

Styling and code:
- Internal CSS only, placed inside each page's <style> block.
- CSS is arranged into separate class rules similar to the provided .box0, .box1, .box2, .box3, .box31, .box32, .box33 and .box4 structure.
- No inline CSS.
- No JavaScript.

How to open:
1. Extract the ZIP.
2. Open index.html in your browser.
3. Use the navigation bar to move between pages.

This is a static front-end demo. Search, authentication, saved applications, and payments are not connected to a backend. Listings and prices are sample content.
